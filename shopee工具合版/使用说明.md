# Shopee 工具合版

将原先三个独立工具（TikTok 下载 / Shopee 竞价导出 / Shopee 视频上传）合并为**一个服务、一个端口（8765）、一个网页**。

打开 http://127.0.0.1:8765 后，在顶部 Tab 切换三个工具，无需分别启动多个窗口。

## 一键启动

双击 `启动.bat`（首次会自动 `npm install` 并自动打开浏览器）。

## 运行测试

```bash
node test.js
```

冒烟测试会临时启动一个服务实例到端口 8865，验证各页面与接口路由（不访问真实 TikTok/Shopee），约 16 项，全部通过即正常。

## 三个工具的使用

### 1. TikTok 无水印视频下载（Tab：TikTok 下载）
- 每行粘贴一个 TikTok 视频链接，填写保存目录，点「开始下载」。
- 大陆网络访问 TikTok 通常需开 VPN/代理（工具自动读取系统代理）。

### 2. Shopee 竞价导出（Tab：竞价导出）
1. 安装浏览器扩展：`extension/` 目录（Edge：`edge://extensions` → 开发人员模式 → 加载解压缩的扩展）。
2. 登录 seller.shopee.cn，点扩展「发送登录信息到本地工具」，把 Cookie 推到本地（8765）。
3. 回到本页「竞价导出」Tab，点「刷新状态」，勾选店铺后点「开始导出」，生成 Excel 到本目录。

### 3. Shopee 视频批量上传（Tab：视频上传）
1. 打开 Shopee「短视频上传」页手动上传一次视频，扩展自动抓取 Cookie/ShopID 并推送到本地（8765）。
2. 回到本页「视频上传」Tab，选择 `.xlsx` 表格（表头含：视频路径 / 视频说明 / 商品编码），点「开始上传」。

## 端口与扩展说明

- 合并服务固定监听 **8765**（原 TikTok 8737、竞价 8765、视频上传 3000 已统一）。
- 三个工具只需加载**一个扩展**（`extension/` 目录），同时负责竞价 Cookie 推送与视频上传凭证抓取。
- 若此前已分别加载过「竞价导出助手」「视频上传凭证抓取」两个旧扩展，请将其**移除**，只保留本合版扩展，避免重复推送。

## 目录结构

```
shopee工具合版/
  main.js           合并后端入口（单端口路由三个模块）
  bidding.js        Shopee 竞价导出模块
  video.js          Shopee 视频上传模块
  tiktok.js         TikTok 下载核心模块
  public/
    index.html      门户页（Tab 切换）
    tiktok/          TikTok 下载页面
    bidding/         Shopee 竞价导出页面
    video/           视频上传页面
    xlsx.full.min.js 视频上传表格解析库
```

## 常见问题

| 现象 | 解决 |
|------|------|
| 端口 8765 被占用 | 关掉旧的 node 黑窗口后重新双击 `启动.bat` |
| 竞导出 403 / 登录失效 | 重新登录卖家中心 → 扩展重推 Cookie |
| 视频上传 401/403 / token is expired | 凭证过期，去短视频上传页手动传一次视频，扩展自动刷新 |
| TikTok 下载网络错误 | 开 VPN/代理后重试 |
