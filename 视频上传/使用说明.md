# Shopee 视频批量上传 · 使用说明

## 首次准备（仅需一次）

1. 安装 [Node.js](https://nodejs.org/zh-cn/download)（LTS 版，安装时保持「Add to PATH」勾选）
2. 装浏览器扩展：Edge/Chrome 打开 `edge://extensions` 或 `chrome://extensions` → 开启「开发者模式」→「加载解压缩的扩展」→ 选择本工具的 `extension` 文件夹
3. 抓取凭证：登录 Shopee 卖家中心，打开 [短视频上传页](https://solutions.shopee.cn/sellers/video-upload/)，**手动上传一个视频**（走完流程即可，无需真正发布），扩展会自动抓到 Authorization/Cookie/ShopID 并推送到本地保存

## 日常使用

1. 双击「**启动.bat**」，工具网页会自动打开（关闭窗口即停止服务）
2. 点网页上的「下载 xlsx 模板」，按列填好：
   - **视频路径**：本机视频的完整路径，如 `C:\视频\1.mp4`
   - **视频说明**：可留空
   - **商品编码**：要关联的商品编码；留空则「只上传、不关联」
3. 确认网页「接口凭证」区显示「✓ 已自动获取凭证」。如果未显示，按上面「首次准备 → 第 3 步」重新抓取
4. 选择填好的 xlsx → 点「解析表格」→ 预览无误 → 点「开始上传」
5. 看日志区进度，全部完成即结束

## 常见问题

| 现象 | 解决 |
|------|------|
| 双击 .bat 提示找不到 node | 重装 Node.js，确保勾选「Add to PATH」 |
| 凭证一直没自动填入 | 确认扩展已启用 + 工具在运行；去短视频上传页手动传一次视频 |
| 上传报 401 / 403 | 凭证过期，按「首次准备 → 第 3 步」重抓 |
| 上传报「上传失败」 | Cookie 过期或缺 session，同上重抓 |
| 商品没匹配上 | 检查商品编码是否正确、是否属于本店 |
| 想先试一下 | xlsx 里先只放 1 个视频跑通，再加量 |
