# Shopee 竞价导出工具 — 极简使用说明

## 安装（仅首次）

1. 打开 `edge://extensions` → 开启「开发人员模式」
2. 「加载解压缩的扩展」→ 选择 `extension` 文件夹

## 使用（每次 3 步）

1. 双击 `启动.bat`
2. 浏览器点扩展图标 → 「发送登录信息到本地工具」
3. 窗口输入店铺 ID 回车 → 生成 Excel。多个店铺可**一次输入**（用逗号或空格分隔，如 `557630453,123456`），也可分多次输入；全部完成后直接回车结束（不用每次重启）

## 常见问题

- **Failed to fetch** → 重新双击 bat，等出现"第 1 步"再点扩展
- **登录已失效（403）** → 重新登录卖家中心，再点扩展
- **端口 8765 被占用** → 关闭多余的黑色窗口
