# Shopee 竞价导出工具（网页版）— 极简使用说明

## 安装（仅首次）

1. 打开 `edge://extensions` → 开启「开发人员模式」
2. 「加载解压缩的扩展」→ 选择 `extension` 文件夹

## 使用（每次 3 步）

1. 双击 `启动.bat`（会自动安装依赖、启动服务并打开网页 `http://127.0.0.1:8765`）
2. 浏览器点扩展图标 → 「发送登录信息到本地工具」→ 回到网页点「刷新状态」，确认「已登录」
3. 在网页上按「分类 / 店铺简称 / 店铺 ID」勾选要导出的店铺（可多选，支持分类全选）→ 点「开始导出」→ 生成 Excel

> 导出的 Excel 保存在 `竞价` 文件夹下，文件名如 `竞价获胜_店铺557630453_2026-08-09_142530.xlsx`。

## 产出目录

导出的 Excel 与 `node_modules`、`session.json` 均位于 `竞价` 目录下（`session.json` 为登录凭证，不入库）。

## 常见问题

- **Failed to fetch / 无法连接服务** → 重新双击 `启动.bat`，再点扩展
- **登录已失效（403）** → 重新登录卖家中心，再点扩展推送，网页点「刷新状态」
- **端口 8765 被占用** → 关闭多余的黑色窗口
