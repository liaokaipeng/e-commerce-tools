# 监控大屏（多店巡检 · 三级告警）

> 面向**使用者**：看什么、怎么用、告警怎么读、常见问题。实现与接口实测形态见《[监控大屏实现](监控大屏实现.md)》《[开放平台链路](开放平台链路.md)》；接入官方 API 见《[新手入门指南](../新手入门指南.md)》「授权店铺」。
>
> **本文件是监控口径与使用说明的唯一权威**。《新手入门指南》为满足「必须自包含」的约束，内联了本文档的入门最小集（打开即巡检、三级告警表、口径差异说明、常见问题）——**改动指标、默认阈值、告警级别语义或常见问题时，两处需手工同步**。

## 1. 这是什么

对「开放平台」已授权的 Shopee 店铺定时巡检，采集**订单履约 / 商品库存 / 账户健康 / 广告投放 / 资金结算 / 售后评价**六个域的数据，按规则产生 **P0（紧急）/ P1（重要）/ P2（提醒）**三级告警，在深色大屏上分级展示。告警**只在大屏展示**（不接 IM）。

**使用前提**：先在门户页「开放平台」Tab 配置 App（partner_id / partner_key）并完成店铺授权。主账号授权一次即带回该账号下全部店铺，无需逐店配置。

## 2. 打开与使用

1. 双击 `启动.bat`，打开门户页 →「监控大屏」Tab。
2. **打开大屏即自动巡检，无需任何额外设置**，打开瞬间立即补一轮采集。
3. **按需采集**：只有大屏打开时才巡检，切走/关闭即暂停，回来立即续采；数据落盘本机、重启后继续积累。

| 区域 | 内容 | 操作 |
|---|---|---|
| 顶栏统计卡 | 店铺数 / P0 / P1 / P2 / 正常（另有「未监控」「待重新授权」按需出现） | P0 红色脉冲；开关「投影」「声音」「轮播」；「金额」切换当地货币 / 人民币 |
| 店铺健康墙（左） | 每店一张卡片：告警徽章、六域最近采集时间 | 颜色 = 最高未关闭告警级别，自动按 P0→P1→P2→正常置顶；点击聚焦该店；「—」= 无此域权限 |
| 趋势 + 矩阵（中） | 7 天趋势曲线（SVG，画阈值虚线）+ 12+ 店 × 19 指标对比矩阵 | 点店铺卡或矩阵行切换店铺；单元格底色 = 告警级别，红框 ✗ = 采集失败（悬浮看原因），`—` = 暂无数据；点单元格看趋势 |
| 告警流（右） | 按 P0→P1→P2 排序的告警列表 | 每条可「详情」「确认」「关闭」；回稳自动标「✓已恢复」；可按级别过滤 |
| 底部 | P0/P1 跑马灯 + 全局采集状态 | 采集失败看店铺卡域状态（✗N次） |
| 告警规则面板 | 23 条规则的启用开关与三级阈值（22 项业务指标 + 1 项采集自检） | 修改立即生效并持久化，留空的级别不触发 |
| 监控店铺面板 | 已授权店铺的监控开关 | 未勾选的店铺不采集、不进大屏（见下） |

「立即采集」按钮：手动触发所选店铺（或全部已启用监控的店铺）立即巡检一轮。

**只想监控部分店铺**：顶栏「监控店铺」面板取消勾选即可——已授权店铺默认全部监控，未勾选的**不再采集、不出现在大屏**，未关闭告警自动关闭（历史数据保留），重新勾选立即恢复；顶栏「未监控」统计卡显示停用数量。

## 3. 监控指标（6 个域 · 22 项）

| 域（频率） | 指标 | 含义 | 默认阈值 P2 / P1 / P0 |
|---|---|---|---|
| 订单履约（每 10 分钟） | 今日待发货 | 今天创建的待发货订单数 | 5 / 15 / 30 单 |
| | 昨日及更早待发货 | 昨天及更早创建、仍未发货的订单数 | 3 / 8 / 15 单 |
| | 待处理取消申请 | 买家取消申请待响应的订单数 | 3 / 8 / 15 单 |
| | 首公里未交接 | 打单后未交付 SLS 转运仓的订单数（跨境特色） | 5 / 15 / 30 单 |
| 商品库存（每 30 分钟） | 断货商品 | 全部型号库存合计为 0 的商品数 | 3 / 10 / 25 个 |
| | 低库存商品 | 合计库存 ≤5 件的商品数 | 10 / 30 / 60 个 |
| | 问题商品数 | 官方「有问题的 listing」清单数量 | 1 / 3 / 8 个 |
| 账户健康（每 60 分钟） | 迟发货率 | 平台周口径迟发货率 | 2 / 3.5 / 5 % |
| | 未完成率 | 取消+退货退款率 | 3 / 5 / 8 % |
| | 店铺评分 | 5 分制，**越小越差** | 4.5 / 4.2 / 4.0 分 |
| | 扣分记录数 | 官方扣分历史记录条数 | — / 1 / 3 条 |
| | 进行中处罚 | 官方处罚记录中「进行中」条数 | — / 1 / 3 条 |
| 广告投放（每 60 分钟） | 今日广告花费 | 官方广告小时报表当日花费合计 | 100 / 300 / 600 元 |
| | 今日广告 ROAS | 当日广告成交额 ÷ 花费（**越小越差**） | 2 / 1 / 0.5 倍 |
| | 今日平均 CPC | 当日花费 ÷ 点击次数 | 2 / 3.5 / 5 元 |
| | 广告账户余额 | 官方广告账户余额（含付费+赠金，**越小越差**） | 50 / 20 / 5 元 |
| 资金结算（每 60 分钟） | 近15天打款金额 | 官方打款明细金额合计（跨境；本土以担保释放列表近似，**越小越差**） | —（默认不告警，按结算节奏自配） |
| | 处理中钱包流水 | 近 15 天钱包流水中 PENDING/INITIAL 记录数（仅本土店铺） | 1 / 3 / 5 笔 |
| | 失败钱包流水 | 近 15 天钱包流水中 FAILED 记录数（仅本土店铺） | — / 1 / 3 笔 |
| | 钱包余额 | 钱包最新余额（仅本土店铺，**越小越差**） | —（默认不告警，按资金安排自配） |
| 售后评价（每 60 分钟） | 近24h退货申请 | 24 小时内创建的退货申请数 | 3 / 8 / 15 单 |
| | 近24h差评 | 24 小时内 1–3 星评价数 | 3 / 5 / 10 条 |

口径说明（与卖家中心看到的可能有细微出入，属正常）：

- **待发货按订单号前 6 位（YYMMDD）分「今天 / 昨天及更早」估算**，接口不返回创建时间，无法精确到小时。
- **库存为全型号合计**；每轮抽查**最近更新的 50 个热点商品**，非全量盘点。
- **迟发货/未完成率为百分数**（3.5 即 3.5%）；**广告指标为当日聚合**，次日 0 点重置，余额含付费与赠金。
- **资金域自动适配**：打款明细仅跨境、钱包流水仅本土；官方接口只返回「已释放」记录，「延迟/冻结」以钱包流水 PENDING/INITIAL 与 FAILED 笔数近似。
- **差评口径**：近 24 小时 1–3 星计差评，关键词命中仅作消息明细、不影响计数。
- **金额单位**：**阈值一律按人民币配置与比较**（自动换算），展示可切当地货币（默认）/ 人民币；币种自动识别（未知按人民币），汇率每日更新、离线回退静态表。
- **无权限自动跳过**（店铺卡「—」，不误报采集失败）；广告/资金/售后三域按官方文档接入、未经生产实测校准。

所有阈值都可在「告警规则」面板按你的店铺实际水平调整。

## 4. 三级告警

| 级别 | 含义 | 视觉 | 响应建议 |
|---|---|---|---|
| P0 紧急 | 正在造成损失或威胁账户（大量断货/严重积压/采集长期失联） | 红色，置顶闪烁 + 声音 | 立即处理（分钟级） |
| P1 重要 | 业务受损正在发生 | 橙色，置顶 | 当日处理（小时级） |
| P2 提醒 | 趋势性风险、观察项 | 黄色 | 关注即可 |

**生命周期**：触发 → 同店同规则去重计数（×N）→ 恶化自动升级 → 回稳自动「✓已恢复」→ 人工「确认 / 关闭」。P2 持续 24 小时未恢复自动升 P1；人工关闭后再触发会重新打开并计数。

**系统自检告警**（监控自身的监控）：某店采集连续失败 1 次 → P2、2 次 → P1、5 次 → P0，恢复采集后自动标记恢复。

**查看告警明细**：点告警卡上的「详情」打开详情抽屉——除级别/状态/触发时间/处理建议外，还列出该告警对应的**具体明细清单**，例如：断货/低库存是哪些商品（商品 ID + 库存合计）、待发货/取消/未交接是哪些订单（订单号 + 创建日期）、问题商品与处罚记录、处理中/失败的钱包流水、退货申请与差评内容等。明细支持关键词过滤与一键复制（制表符分隔，可直接贴进表格），最多保留最新 200 条；下次采集后明细自动刷新。

**授权失效（待重新授权）**：凭证确认死透（access_token 无效、refresh_token 与店铺不匹配等）时，店铺被标记「需重新授权」并**暂停采集**（不再打失败请求），店铺卡置灰、顶部横幅附一键跳「开放平台」按钮；重新授权后**立即恢复采集**（无需等巡检周期）。

## 5. 数据与隐私

数据仅存本机 `server/data/monitor/`（gitignored）：快照保留 90 天、金额存当地货币原始值；另有告警（含明细清单，最多 200 行/条）、阈值覆盖、店铺配置与汇率缓存。不含凭证与买家敏感信息（订单仅展示订单号与创建日期，不含收件人/地址等）；采集全部走只读查询接口，不改动店铺任何数据。

## 6. 常见问题

- **提示「尚未配置开放平台 App / 没有已授权店铺」**：去「开放平台」Tab 配置 App 并完成店铺授权即可。
- **店铺显示「采集连续失败」或「待重新授权」**：授权已失效，到「开放平台」Tab 重新生成授权链接、主账号登录授权一次即可全部恢复（授权成功后大屏立即恢复采集）。原因：共享 token 被某店铺刷新绑定后其余店铺需重新授权（官方 FAQ138 Q8 语义）。
- **告警数与卖家中心不完全一致**：见第 3 节口径说明（按天估算、抽查 50 个热点商品、平台口径快照）；阈值不贴合可在规则面板调整。
- **只想监控重点店铺**：顶栏「监控店铺」面板取消勾选（不采集、不进大屏，重新勾选即恢复）；确定不再使用的店铺可在「开放平台」Tab 删除其授权。
- **某店某域长时间 ✗**：悬浮店铺卡底部的域状态看最近错误；多为授权或网络问题，先按第二条重新授权。
