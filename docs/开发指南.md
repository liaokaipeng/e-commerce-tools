# 开发指南（面向开发者）

> 面向**开发者**：后端约定、新增工具步骤、测试与调试。总体架构与目录结构见《[架构](架构.md)》；三条长链路的实现详解见《[视频上传链路](视频上传链路.md)》《[开放平台链路](开放平台链路.md)》《[监控大屏实现](监控大屏实现.md)》；使用者视角见《[监控大屏](监控大屏.md)》与《[新手入门指南](../新手入门指南.md)》。

## 1. 快速开始

```bash
npm i
node server/main.js              # 后端 http://127.0.0.1:8765
node test/test.js                # 测试（单元 + 开放平台刷新链路 + 接口冒烟，临时端口 8865）

cd frontend && npm install && npm run dev    # 前端开发 http://localhost:5173（/api 代理到 8765）
cd frontend && npm run build                 # 构建到 frontend/dist，由 main.js 托管
```

日常使用双击 `启动.bat` 一键起服务（详见《[新手入门指南](../新手入门指南.md)》）。

## 2. 后端约定

- **CommonJS**：`require` / `module.exports`，不要混用 ESM；保持文件原有风格。
- **路由注册模式**：业务模块导出 `register({ get, post })`，由 `main.js` 在启动前统一调用；处理函数签名 `(req, res, url)`（`url` 为含 query 的 `new URL(...)`）。

```js
function register({ get, post }) {
  get('/api/xxx/status', handleStatus);
  post('/api/xxx/start', handleStart);
}
module.exports = { register };
```

- 其余约定（响应 `sendJson` / 请求体 `readJsonBody`·`readRouteBody`·`jsonAction` / 出站 `http.js` / 长任务 `jobs.js` / 重试 `retry.js` / 凭证不入库 / 端口 8765）见《[架构](架构.md)》§3；对接 Shopee 开放平台接口前先查 `docs/shopee_api_doc/`，调官方 Open API 统一走 `callOpenApi`（见《[开放平台链路](开放平台链路.md)》§3），不要自行拼签名。
- 改动入口/端口/结构须同步更新文档（见 `AGENTS.md` 约束 7）。

## 3. 新增一个工具/模块的步骤

1. 新建 `server/xxx.js`，实现 `register({ get, post })` 注册路由；需要纯函数时放入 `server/lib/` 便于单测。
2. 在 `server/main.js` 顶部 `require` 并调用 `xxx.register({ get, post })`。
3. 前端新增一个多页入口：新建 `frontend/src/xxx/index.html`（HTML 入口与页面源码同目录，`main.js` / 组件都放这里；vite `root = src`），并在 `vite.config.js` 的 `rollupOptions.input` 以 `src('xxx/index.html')` 登记——构建产物自动落 `dist/xxx/index.html`，页面 URL 不变；样式复用 `src/styles/base.css` 的设计令牌（浅色）或 `monitor/monitor.css` 的 `--d-*`（深色），**不要另写一套色值/尺寸**（见《[架构](架构.md)》§4）。
4. 门户页 `frontend/src/portal/tabs.js` 增加一条 Tab（`group` 决定侧栏分组，新分组记得加进同文件的 `GROUP_ORDER`）。
5. 在 `test/api.test.js`（接口）与 `test/unit.test.js`（纯函数）补充用例。
6. 更新 `docs/架构.md`（目录结构 / API 表）、对应链路文档、`AGENTS.md`、本文档；新增的 Shopee 官方接口资料同步到 `docs/shopee_api_doc/`。
7. 跑 `node test/test.js` 全绿后提交。

> 若新工具需要外部可执行文件（如视频压缩的 ffmpeg）：**不要加进 `package.json`，也不要塞进发布包**——按 `server/compress/ffmpeg.js` 的模式做「探测已有 → 页面一键下载到 `bin/`（gitignored）」。

## 4. 测试

```bash
node test/test.js   # 或 npm test；全部通过即正常（退出码 0）
```

三类测试（均**不访问真实站点**），结果汇总一份：

1. **单元测试** `test/unit.test.js`（编排入口：逐主题串行执行 `test/unit/*.test.js`）：纯函数，不启动服务。覆盖视频上传纯函数（md5/etag/AES/SigV4/MP4 探测/行校验）、TikTok 链接与代理检测、**视频压缩计划（达标判定 / 码率与 atempo·scale 滤镜 / 命令行拼装 / 产物命名 / 递归扫描过滤）**、竞价金额换算、取消竞价待改进列表解析、开放平台签名与打码、任务取消（`video._test` 确定性驱动 `processJob`）、共享层契约（`lib/jobs` 暂停/继续/取消/SSE 断开/TTL、`lib/retry` 次数与退避策略、`readRouteBody` 非法 body 回 400、CORS 白名单、Cookie 罐 TTL 回收）。用例按主题拆分（video / tiktok / compress / bidding-cancel / openapi / shared-layer / http / monitor / monitor-engine）。**压缩用例只碰 `plan.js` / `scan.js` 这类不触发子进程的模块**——`probe.js` / `run.js` 会 spawn ffmpeg，别在单元测试里调（本机没装 ffmpeg 就会红）。
2. **开放平台刷新链路** `test/openapi-refresh.test.js`：替换出站为离线 mock 网关（不启动服务、不触网），验共享 token 组整组续期、独立凭证按店刷新、认证失败强制刷新、并发刷新单店只发一次、批量刷新按组去重与失效标记（缓存隔离见下方说明）。
3. **接口冒烟测试** `test/api.test.js`：以 `PORT=8865` 临时启动服务，验页面静态资源、各模块 API 路由、SSE 端到端（含迟到回放）、任务取消、控制类接口（pause/resume/cancel 对未知 jobId 回 404、非法 JSON 回 400）、CORS 403、开放平台登录（未配置/保存/打码/删除幂等/回调页）、**视频压缩（status / scan 递归与排除产物目录 / 目录不存在时回可读 400 而非 Node ENOENT）**、404 兜底。压缩这部分只验不需要 ffmpeg 的分支——`/api/compress/run` 用不存在的目录拿 400，**不要**在测试里真跑压缩（会 spawn ffmpeg 并写用户磁盘）。

`test/helpers.js` 提供 `t()` 断言、`req()` 请求封装、`removeFile()`（绕开本机安全删除 shim 的批量删除阈值）、`startServer()`（自动备份并原样恢复 `server/data/` 下四个 session/settings 文件）；开放平台凭证经 `OPENAPI_SESSION_FILE` 隔离到临时文件。

> **数据目录隔离**：`test/unit.test.js`（编排入口在 require 子模块前设置）与 `api.test.js` 都必须把 `MONITOR_DATA_DIR` 指向临时目录后再 `require` 监控模块。否则 `store` 会读到 `server/data/monitor/rules.json` 里**用户真实保存的规则覆盖**，阈值类断言会随用户配置漂移（曾出现 `ads.spend_today` 被覆盖为 1000/3000/6000，导致「500 泰铢触发 P2」断言失败）。汇率同理：金额场景先调 `currency._test.lockStaticRatesForTest()` 钉死内置静态汇率，避免在线汇率让数值断言随机失败。

> **mock 网关类测试必须清干净 require 缓存**：`test/openapi-refresh.test.js` 在设 `OPENAPI_SESSION_FILE`、替换 `lib/http.request` 之后，要把 `openapi.js` require 的**每个**子模块（`store` / `client` / `refresh-all` …）都从 `require.cache` 删掉——这些子模块在 `unit.test.js` 阶段已随 `openapi.js` 加载过，内部持有的 store 指向**真实** `openapi-session.json`、持有的 `request` 是替换**之前**解构的原始实现。漏清即命中旧实例：测试会真的向 Shopee 网关发请求，并把结果写回用户真实凭证文件（「不访问真实站点」直接破功）。**给 `server/openapi.js` 新增子模块时，同步补进那份缓存清理清单。**

> **定位后端 500**：`KP_TEST_SERVER_LOG=1 node test/test.js` 会把被测子进程 stderr 透传到测试输出。

新增用例：纯函数在 `test/unit/` 对应主题文件（如 `monitor.test.js`、`shared-layer.test.js`）的 `run()` 追加 `t(...)`，新开主题文件后记得在 `test/unit.test.js` 的 `modules` 列表按序登记；API 路由在 `api.test.js` 的 `run()` 用 `req` / `readSSEUntil` 追加，勿触发真实网络调用。

其余无自动化：TikTok 下载 / 竞价导出 / 取消竞价 / 视频上传按真实流程手测。

**视频压缩的自动化边界**：单元测试只覆盖 `plan.js` / `scan.js`（不 spawn 子进程），接口冒烟只验「目录不存在回 400」这类不需要 ffmpeg 的分支。**真实压缩效果（码率是否收敛、时长是否截断、取消是否清掉半成品）必须手测**：造一段超标素材（例：180 秒 / 260MB）丢进空目录 → 页面选目录 → 扫描 → 执行，核对产物落在 `<源>/compressed/` 且同时满足 `≤30MB` 与 `≤60s`；`trim` 与 `speed` 两种超长模式各跑一次；取消一次确认 `compressed/` 下不留半成品文件。**别把真跑压缩塞进 `test/api.test.js`**——会 spawn ffmpeg 并往磁盘写产物。

> **页面手测会改用户真实数据，跑完必须还原**：`test/helpers.js` 的 `startServer()` 会自动备份并还原 `server/data/` 下的 session 与 `settings.json`，但**手动跑的临时服务没有这层保护**——在页面上点「记住目录」会经 `POST /api/settings` 把路径写进用户真实的 `server/data/settings.json`（曾把临时夹具目录写进 `compress.dir`，用户下次打开页面默认目录变成已删除的临时路径）。**手测用临时端口起服务，收尾时手动把 `settings.json` 里被写脏的键删掉**，并删掉自己造的夹具目录（曾一次残留 926MB）。

### 5.1 开放平台接口报参数错误怎么查（经验沉淀）

网关的 `error_param` 类报错**经常是误导性的**：参数位置/类型/签名基串任一不符，报错文案会在多条错误间“连锁漂移”（实测 `the format of shop_id parameter is wrong` → `It should have partner_id in the request body` → `Wrong sign` 依次出现，真实原因却是签名基串与参数类型）。**不要按报错文案字面去改**，按下面顺序排查：

1. **先查文档**：在 `docs/shopee_api_doc/` 点开对应接口核对参数名、必填项、分页字段（如 `order/get_order_list` 必填 `time_range_field + page_size`；`product/get_item_list` 缺 `item_status` 报 `product.error_unknown`）。
2. **最小参数组合逐变体验证**：先只留公共参数确认签名正确，再逐个加参数（sign 通过后报错进入下一层校验，可据此逐层定位）。
3. **参数类型与方法**：JSON body 里的 id 类参数（`partner_id` / `shop_id`）必须**数字类型**；查询类接口用 GET、写操作/换 token 用 POST（详见《[开放平台链路](开放平台链路.md)》§2）。
4. **签名基串**：业务接口 `partner_id + api_path + timestamp + access_token + shop_id`；`access_token/get` 刷新接口特殊（详见《[开放平台链路](开放平台链路.md)》§2）。
5. **真实接口验证只做只读 GET**，且优先用测试/沙箱环境；生产联调完清掉本地测试数据（如 `server/data/monitor/`）。

实测接口形态沉淀在《[开放平台链路](开放平台链路.md)》与《[监控大屏实现](监控大屏实现.md)》。
