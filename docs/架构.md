# 架构文档

> 面向**开发者**：总体架构、目录结构、API 路由总表与后端约定。三条长链路的实现详解见《[视频上传链路](视频上传链路.md)》《[开放平台链路](开放平台链路.md)》《[监控大屏实现](监控大屏实现.md)》。

## 1. 总体架构

单服务、单端口（8765）、单网页：一个 Node 后端托管前端构建产物并注册全部 API；前端为 Vue3 + Element Plus 多页应用，门户页按 Tab 切换各工具、开放平台与监控大屏；一个 MV3 扩展向本地服务推送凭证。技术栈详见 `AGENTS.md` 速查。

```
浏览器（Edge / Chrome）
   ├─ 门户页 + 工具页 + 监控大屏（frontend/dist，由后端托管）
   └─ 扩展「KP工具合集助手」（extension/）：推送 Cookie / 凭证
           ▼
本地 Node 服务 server/main.js（http://127.0.0.1:8765）
   ├─ tiktok.js       TikTok 无水印下载
   ├─ bidding.js      Shopee 竞价导出
   ├─ bidding-cancel.js  Shopee 取消竞价
   ├─ hotlisting-cancel.js  Shopee 取消注册 Hot Listing
   ├─ product-export.js  Shopee 跨境商品数据导出（规格行 + SKU 图片链接）
   ├─ video.js        视频批量上传（链路拆到 video/）
   ├─ openapi.js      开放平台登录（链路拆到 openapi/）
   └─ monitor.js      多店监控大屏（链路拆到 monitor/）
           │ 出站请求（server/lib/http.js）
           ▼
       Shopee / TikTok 线上接口
```

各工具链路：

| 工具 | 后端模块 | 前端页面 | 链路 |
|---|---|---|---|
| TikTok 无水印下载 | `server/tiktok.js` | `frontend/src/tiktok/` | 直连解析 → 第三方接口兜底 → 分地址下载 |
| Shopee 竞价导出 | `server/bidding.js` | `frontend/src/bidding/` | 扩展推 Cookie → seller 接口拉获胜数据 → ExcelJS 导出 |
| Shopee 取消竞价 | `server/bidding-cancel.js` | `frontend/src/bidding-cancel/` | 共用 Cookie → `get_item_ongoing_list(page_tab=2)` 拉待改进 → `seller_withdraw(bid_id)` 逐条撤销 |
| Shopee 取消注册 Hot Listing | `server/hotlisting-cancel.js` | `frontend/src/hotlisting-cancel/` | 共用 Cookie → 按店铺配置 SPU（`data/hotlisting-spu.json` 持久化）→ `get_rsku_vsku_list(rsku_status=2)` 拉已注册且 `qualification_flags=1` → `update_enroll(seller_decision=0)` 逐条取消 |
| Shopee 商品数据导出 | `server/product-export.js` | `frontend/src/product-export/` | 共用 Cookie → `opt/mpsku/list/v2/get_product_list` 翻页 + `product/get_product_info` 拉规格 → 每规格一行（含 SKU 图片直链）ExcelJS 导出 |
| Shopee 视频批量上传 | `server/video.js` | `frontend/src/video/` | 抓凭证 → preupload/分片/PUT/merge/report → video/create 发布 |
| Shopee 开放平台登录 | `server/openapi.js` | `frontend/src/openapi/` | 录入 App → 授权链接 → 回调换 token → `access_token/get` 刷新 |
| Shopee 多店监控大屏 | `server/monitor.js` | `frontend/src/monitor/` | 定时巡检六域 → 快照 + 规则引擎 → P0/P1/P2 告警 → SSE 推大屏 |

## 2. 目录结构

```
kp_tools/
  server/               后端（Node CommonJS）
    main.js             入口：路由表 + 静态托管 + 服务启动（不做业务）
    tiktok.js / bidding.js / bidding-cancel.js / hotlisting-cancel.js / product-export.js / video.js / openapi.js / monitor.js
                        业务模块路由注册（bidding 店铺列表热载自 config/stores.json）
    tiktok/             TikTok 下载子模块：constants（常量/UA/sleep）、proxy（代理）、request（出站）、parse（解析/下载）、job（批量编排）
    video/              视频上传子模块（constants/request/creds/upload-cn/upload-ph/job，职责见《视频上传链路》）
    openapi/            开放平台子模块（constants/store/client，职责见《开放平台链路》）
    monitor/            监控大屏子模块（constants/rules/store/collectors/engine/scheduler，职责见《监控大屏实现》）
    lib/                通用库：http-utils（响应/请求体/静态/SSE）、http（统一出站）、settings（默认目录）、config（端口常量）、shopee-session（卖家中心会话/Cookie/店铺列表/金额，竞价四模块共用）、video-utils / openapi-utils（纯函数）

                        composables（useToolPage/useShopeeSession）、styles/base.css
    dist/               构建产物（由 main.js 托管，gitignored）
  extension/            浏览器扩展（MV3）：manifest、background（抓凭证推 /api/creds）、popup（竞价 Cookie）
```

## 3. 后端分层与约定

- **路由注册与链路分离**：业务模块导出 `register({ get, post })`，由 `main.js` 启动前统一调用并入「方法 + 路径」路由表；链路较长的模块入口只留路由注册，常量 / 出站 / 解析 / 编排拆到同名子目录。
- **通用能力下沉 `lib/`**：`sendJson` / `readBody` / `serveStatic` / `sse` / `createDispatcher`（路由分发 + 异步错误兜底 500）在 `http-utils.js`；出站统一走 `http.js` 的 `request`——按 host 维护 Cookie 罐（`useJar: true`）、`body` 支持 Buffer / 字符串 / 流、`signal` 可中断。
- **凭证不入库**：`bidding-session.json` / `video-session.json` / `openapi-session.json` / `settings.json` 统一存 `server/data/`（gitignored）；日志不完整打印 Cookie / Authorization / token；partner_key 与 token 对外一律 `maskToken` 打码。
- **端口固定 8765**（扩展与文档已硬编码）：`lib/config.js` 区分监听端口 `LISTEN_PORT`（默认 8765，可用 `PORT` 环境变量覆盖，仅供测试/调试）与 OAuth 回调端口 `CALLBACK_PORT`（固定 8765，不随监听端口变化）；两者不一致时 `main.js` 启动即告警。改入口 / 端口 / 结构时，同步更新 `启动.bat`、本文件、`AGENTS.md` 与涉及链路的文档。

## 4. 前端

Vue3 + Element Plus + Vite 多页应用（监控大屏折线图用 ECharts），九个入口在 [vite.config.js](../frontend/vite.config.js) 的 `rollupOptions.input` 登记，构建到 `frontend/dist` 由 `main.js` 托管。

- 路径映射：`/` → 门户页，`/tiktok/` `/bidding/` `/bidding-cancel/` `/hotlisting-cancel/` `/product-export/` `/video/` `/openapi/` `/monitor/` → 工具页（`http-utils.js` 的 `DIR_INDEX`）。
- 九个入口统一经 `src/bootstrap.js` 挂载（Element Plus 注册 + `#app`）；tiktok / bidding / bidding-cancel / hotlisting-cancel / product-export / video / openapi 共用 `styles/base.css` 与 `components/`（LogPanel / DirRow / LoginCard / StorePicker）。
- 共享逻辑：tiktok / bidding / bidding-cancel / hotlisting-cancel / product-export / video 共用 `useToolPage.js`（日志 / 默认目录 / 日志滚动 / SSE 读取），bidding / bidding-cancel / hotlisting-cancel / product-export 共用 `useShopeeSession.js`（登录轮询 + 店铺勾选），新增工具页优先复用。
- 视频上传拆「跨境」「本土」两个 Tab，共用 `/video/` 页面，经 `?mode=cn|ph` 固定站点；开放平台页为 App 配置 / 授权链接 / Token 管理；监控大屏页为深色三栏（健康墙 / 趋势矩阵 / 告警流）+ ECharts 折线 + SSE 推送（详见对应链路文档）。

## 5. 浏览器扩展

一个 MV3 扩展（`extension/`）同时负责两类凭证：

- **竞价**：popup 点按钮 → 推 Cookie 到 `/api/cookie`，存 `bidding-session.json`。
- **视频上传**：`background.js` 监听 `webRequest`，按站点（`shopee.cn` / `shopee.ph`）抓 `Authorization` / `Cookie` / `shop_id` / `userId` → 推 `/api/creds`，存 `video-session.json`；凭证同时缓存 `chrome.storage.local`（服务未启动不丢），抓到新请求时**整包重推**。

注意：`manifest.json` 的 `host_permissions` 与 `FILTER` 需覆盖对应 `shopee.{cc}` 域；`detectSite` 忽略 `shopee.sg`。
