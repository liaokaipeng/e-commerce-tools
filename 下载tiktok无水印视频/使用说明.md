# TikTok 无水印视频下载工具

## 使用步骤

1. 双击 **`启动.bat`**（首次运行会自动安装依赖），浏览器自动打开工具页面
2. 在输入框中粘贴 TikTok 视频链接（每行一个，支持短链接）
3. 选择保存位置（默认：`下载\tiktok_videos`）
4. 点击 **开始下载**

## 说明

- 视频以 **视频 ID 命名**，保存为 `.mp4` 无水印文件
- 失效/已删除的链接会自动**跳过**，不影响其他视频；已下载过的会自动跳过不重复下载
- 下载提示网络错误时：**开启 VPN/代理**后点「重新检测网络」再下载（工具会自动读取系统代理）
- 关闭下载窗口即停止服务；以后使用直接双击 `启动.bat` 即可

## 环境要求

- 需要安装 [Node.js](https://nodejs.org/)（LTS 版本即可）
